# Informes de incidente (entrega individual)

Cada estudiante sube **un** informe de respuesta a incidente de la Sesión 5, usando
la plantilla [`../PLANTILLA-informe-incidente.md`](../PLANTILLA-informe-incidente.md).

## Convención de nombre (obligatoria)

```
nombre-y-dependencia.md        (o .pdf)
```

- Todo en minúsculas, palabras separadas por guiones, sin tildes ni espacios.
- `dependencia` = tu área/dependencia laboral.

**Ejemplos:**
```
juan-perez-contabilidad.md
maria-gomez-ti-infraestructura.pdf
luis-rojas-seguridad-informatica.md
```

## Cómo entregar

1. Copia la plantilla, renómbrala con tu nombre-y-dependencia y complétala.
2. Colócala en esta carpeta (`informes/`).
3. Súbela al repositorio (commit + push) **o** entrégala directo al docente, según
   te indique.

> Un informe por persona. El contenido debe basarse en evidencia (hashes, queries
> del SIEM, salidas de Velociraptor). Ver la rúbrica que aplica el docente.
